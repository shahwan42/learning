# Exercises

One per lesson. Small, realistic, modelled on real `cashflow-console` code.

Workflow: read the exercise `README.md`, write your attempt in the provided file, tell me it's ready.
I review for correctness **and** idiomatic usage, then progress gets updated.

## Optional: a runnable playground

Most early exercises are reviewable by reading. When you want to actually run one:

```bash
npm create vite@latest playground -- --template vue-ts && cd playground && npm install && npm run dev
```

Run that from `vue_study/exercises/`. It gives you a scratch Vue 3 + TS + Vite app on `localhost:5173`.
Not required for exercise 01.
