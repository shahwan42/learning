# Exercises

One file per exercise, named `<topic-id>-<slug>.md`. Answers go inline in the file or in chat.

Conventions:

- **Paper exercises** ask you to predict before measuring. Predicting badly and then measuring is the whole point — don't run it first.
- **Lab exercises** need `study-project/lab` up. See [lab-setup.md](../prerequisites/notes/lab-setup.md).
- **Code exercises** are PHP 8.3 / Laravel. Idiomatic beats clever; I'll flag both correctness and style.
