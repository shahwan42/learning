# Track: genres — The documents you ship

Anchor: the cross-team RFC (the PE3 promotion bar). Each genre is a contract with the reader; templates encode the contract.

## Topics
1. ADRs — context → decision → consequences; why one page is enough — not started
2. Design docs (SDDs) — problem framing, options & tradeoffs tables, non-goals — not started
3. Cross-team RFCs — stakeholder map, socializing before publishing, driving comments to a decision, lifecycle — not started
4. Postmortems — blameless narrative, timeline discipline — not started
5. PR descriptions & review comments — context-setting, actionable tone — not started
6. Docs that live — runbooks/how-tos, fighting doc rot — not started

Capstone: write a real cross-team RFC end-to-end on a real Foodics topic — socialize it, drive it to a decision.
