# Exercises

One directory per exercise: `NN_slug/`. Your attempt lives here; after review, the corrected version stays as reference. Each exercise ends with the close-out block (`residue:` / `edges:` / `work hook:` — see `../../AGENTS.md`).
House style: where the domain allows, the task opens with **written predictions or a cold attempt before anything runs**; the review grades the prediction gap. From a track's third unit onward, one small sub-task exercises an earlier demonstrated unit in the new context. Weekly katas land in `katas/`.
