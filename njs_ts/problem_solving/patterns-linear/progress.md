# Track: patterns-linear — arrays, strings, and friends

Why this track: linear-structure patterns are the highest-frequency interview material, and each is a reusable template, not a memorized solution. Per topic: trigger cue → template → 1–2 problems.

| # | Topic | Trigger cue ("when you see…") | Status |
|---|---|---|---|
| 1 | Two pointers (converging) | sorted input; pair / palindrome questions | ⬜ |
| 2 | Two pointers (reader/writer) | in-place removal or compaction | ⬜ |
| 3 | Sliding window (fixed size) | "every window of size k" | ⬜ |
| 4 | Sliding window (variable size) | "longest/shortest subarray such that…" | ⬜ |
| 5 | Hash patterns: frequency, grouping, seen | "count / group / first duplicate / anagram" | ⬜ |
| 6 | Prefix sums (+ hash map combo) | "subarray sum / range total" | ⬜ |
| 7 | Stack | nesting, matching, "most recent unfinished thing" | ⬜ |
| 8 | Binary search on arrays | sorted + "find position"; O(log n) demanded | ⬜ |
| 9 | Binary search on the answer | "minimum speed/capacity so that…" | ⬜ |
| 10 | Intervals | "merge / overlap / meeting rooms" — sort by start, sweep | ⬜ |
| 11 | Linked lists | reversal; fast/slow for cycle & middle | ⬜ |
