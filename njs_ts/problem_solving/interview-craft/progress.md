# Track: interview-craft — performing the skill

Why this track: solving at your desk and solving in an interview are different skills; this trains the second. Unlocks after ~4 patterns-linear topics so there's material to perform with.

| # | Topic | Why | Status |
|---|---|---|---|
| 1 | Working a problem out loud | restate → examples → brute force → commit to complexity → code; this is what interviewers grade | ⬜ |
| 2 | Debugging under pressure | tiny repro inputs, trace tables, `node inspect` / VS Code debugger on a failing test | ⬜ |
| 3 | Complexity analysis on demand | state time/space in one breath for any past solution | ⬜ |
| 4 | TypeScript re-solves | typing solutions and data structures; Node 26 runs .ts directly | ⬜ |
| 5 | Timed sets + mistake log | 25-min problems, spaced re-solves, tracking *why* attempts fail | ⬜ |
