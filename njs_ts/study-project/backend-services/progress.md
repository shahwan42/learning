# Track: backend-services

Build and run a production-shaped HTTP API. Capstone: one small real API built incrementally across topics 2–8.

Legend: ☐ not started · ▶ in progress · ✅ done

1. ☐ HTTP in Node — node:http fundamentals; what frameworks actually add
2. ☐ Framework — Fastify: routing, hooks, plugins, lifecycle
3. ☐ Validation & typed handlers — zod + framework integration; never trust req.body
4. ☐ Config & environments — env vars, validated config, secrets hygiene
5. ☐ Database access — pg + Drizzle (or Prisma); pooling, transactions, N+1
6. ☐ Auth — sessions vs JWT, middleware placement, common mistakes
7. ☐ Testing — vitest, HTTP-level tests, what to test at which layer
8. ☐ Production failure modes — timeouts, graceful shutdown, retries, pool exhaustion, memory leaks
9. ☐ Packaging & deploy — Docker for Node, NODE_ENV, signals in containers
