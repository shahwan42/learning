# Exercises

```bash
go run ./01-goroutines
go vet ./...
go run -race ./01-goroutines    # from Debugging §1 onward, this becomes the default
```

Rules of engagement: attempt it, paste or leave the code, and I'll review for correctness and idiom
before anything gets marked done. Wrong-but-reasoned beats copied-and-correct — the review is where
the learning is.
