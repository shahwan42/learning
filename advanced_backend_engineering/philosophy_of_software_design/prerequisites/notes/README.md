# Prerequisites

Taught just-in-time, only when a lesson needs it. Notes land here as we go.

Likely to come up, in rough order:

- PHP 8.1+ enums and readonly classes — the cheap fix for meaning coupling
- Laravel service container: binding interfaces, contextual binding, why `app()` calls are a smell
- Eloquent vs. data-mapper thinking — what "the model is your schema" costs you
- PHPStan/Larastan levels — what each level actually starts catching
- Pest/PHPUnit test doubles: fake vs. stub vs. mock, and which one couples your test to implementation
- Deptrac basics — enforcing dependency direction in CI
