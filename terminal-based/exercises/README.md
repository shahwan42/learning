# Exercises

One file per exercise, created live during sessions — nothing pre-generated.

Naming: `<track>-<topic>-<slug>.md` (e.g. `shell-A2-stderr-detective.md`).
Each file holds: the task → your attempt (pasted in) → review notes → verdict → close-out block (`residue:` / `edges:` / `work hook:` — see `../../AGENTS.md`). A topic's checkbox in its track `progress.md` flips to `[x]` only after the review shows understanding.
House style: where the domain allows, the task opens with **written predictions or a cold attempt before anything runs** (see `shell-A1-argv-microscope.md`); the review grades the prediction gap, not just the final state. From a track's third unit onward, one small sub-task exercises an earlier demonstrated unit in the new context.
