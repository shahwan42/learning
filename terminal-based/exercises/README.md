# Exercises

One file per exercise, created live during sessions — nothing pre-generated.

Naming: `<track>-<topic>-<slug>.md` (e.g. `shell-A2-stderr-detective.md`).
Each file holds: the task → your attempt (pasted in) → review notes → verdict. A topic's checkbox in its track `progress.md` flips to `[x]` only after the review shows understanding.
